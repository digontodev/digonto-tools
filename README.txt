DIGONTO TOOLS 5.0  -  capture, crop, match, remove background
==========================================================
Part of the Digonto apps (digonto.dev). This is the tool part of the former "Digonto Images".
The photo editor is now Digonto Images, the vector editor Digonto Vector (separate programs).

  Same layout as Digonto Images: tools in the column on the left, your pictures as tabs, settings in the panels on the right.
    Screen capture     Full screen, drag an area, or click a window (delay + hide-window options)
    Phone (ADB)        Add a phone by ip:port (Connect / Disconnect / Pair), list + refresh devices, screenshot
    Crop & coordinates Drag a box -> save template PNG; click the tap point -> offset_x / offset_y
    Verify match       Finds a template in a screenshot exactly like the bot (score, box, tap point)
    Remove background  Auto (4 corners) / Manual (click) / AI (rembg). Original pixels stay 100 % identical
    Setup              Shows what is installed, "Install everything that is missing", folder locations
  Several pictures can be open at once (tabs); drop files on the window to open them. Mouse wheel zooms.

Your settings and the folder of the older program (~/Digonto Images or ~/ImageTools) are picked up automatically.
Installing Digonto Tools removes the old Digonto Images program (your pictures and templates are not touched).
AI background removal is an optional download (about 500 MB); it is not available on Intel Macs.
